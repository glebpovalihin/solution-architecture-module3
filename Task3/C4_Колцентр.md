# C4. Прогнозировать нагрузку на кол-центр для планирования смен (Container)

```plantuml
@startuml
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Container.puml
LAYOUT_TOP_DOWN()
title C4 Container - Прогноз нагрузки на колцентр

Person(planner, "Сотрудник", "Составляет и утверждает расписание")

System_Boundary(bank, "Контур банка") {
    System_Ext(ats, "система кол центра", "Почасовые логи: объем, метаданные, потерянные вызовы")
    System_Ext(cal, "Календарные данные", "Праздники, дни выплат и налоговых платежей")
    Container(ingest, "Ingestion Service", "Python/Airflow", "Загрузка логов, расчет спроса")
    ContainerDb(ts, "Time Series Store", "PostgreSQL", "Ряды нагрузки по интервалам")
    Container(forecast, "Forecast Service", "LightGBM, прогнозы", "Прогноз по часам на 2-4 недели + интервал")
    Container(wfm, "WFM Adapter", "код", "Перевод прогноза в требуемый штат по сменам")
    System_Ext(wfmsys, "WFM-система", "Расписание смен")
    Container(mon, "Monitoring", "Prometheus/Grafana", "Покрытие интервала, отклонения")
}

Rel(ats, ingest, "Логи звонков")
Rel(cal, ingest, "данные по датам")
Rel(ingest, ts, "Нормализованные ряды")
Rel(ts, forecast, "История + признаки")
Rel(forecast, wfm, "Прогноз + интервал")
Rel(wfm, wfmsys, "Потребность в штате")
Rel(planner, wfmsys, "Утверждение расписания")
Rel(forecast, mon, "интервалы")
Rel(ats, mon, "Факт vs прогноз")
@enduml
```

Границы доверия:
- вход - логи колцентра
- выход в WFM (прогноз - рекомендация)
- Режим - пакетный расчет раз в день/неделю
