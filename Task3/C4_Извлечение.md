# C4. Извлекать финансовые показатели из неструктурированных бухгалтерских документов и банковских выписок

```plantuml
@startuml
!include https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Container.puml
LAYOUT_TOP_DOWN()
title C4 Container - Извлечение финпоказателей

Person(underwriter, "Сотрудник", "Проверяет и подтверждает поля")

System_Boundary(bank, "Контур банка") {
    System_Ext(loan, "Кредитный конвейер", "Заявки и пакеты документов")
    Container(gw, "Doc Intake", "Java", "Прием пакета, классификация типа документа")
    Container(ocr, "OCR Service", "", "Текст + layout из сканов и фото")
    Container(extract, "Extraction Service", "LLM + JSON-схема", "Поля + ссылка на фрагмент + уверенность")
    Container(validate, "Validation Service", "код", "JSON-схема, арифметика баланса")
    Container(ui, "Review UI", "Web", "Карточка заявки")
    ContainerDb(db, "Field Label Store", "PostgreSQL", "Подтвержденные значения, исправления")
    Container(mon, "Monitoring", "Prometheus/Grafana", "Точность по полям, доля правок")
}

Rel(loan, gw, "Пакет документов")
Rel(gw, ocr, "Сканы/фото")
Rel(gw, extract, "Excel/выгрузки (текст)")
Rel(ocr, extract, "Текст + layout")
Rel(extract, validate, "JSON полей + источники")
Rel(validate, ui, "Валидная карточка")
Rel(validate, extract, "Разовый повтор обработки при невалидной схеме")
Rel(underwriter, ui, "Проверка, правки, подтверждение")
Rel(ui, db, "Подтвержденные поля")
Rel(db, extract, "примеры / дообучение")
Rel(extract, mon, "Метрики")
Rel(ui, mon, "Время пакета, доля правок")
@enduml
```

Границы доверия:
- вход документов от клиента это недоверенный контент
- выход LLM -> Validation
- пилот - передача документов в выделенный контур провайдера (договор обработки, TLS, запрет обучения на данных банка в договоре)
