## Выбранные три инициативы

- Автоматически выявлять подозрительные операции по счетам
- Прогнозировать нагрузку на кол-центр для планирования смен
- Извлекать финансовые показатели из неструктурированных бухгалтерских документов и банковских выписок

### Обоснование выбора инициатив

| Критерий | Автоматически выявлять подозрительные операции по счетам | Прогнозировать нагрузку на кол-центр для планирования смен | Извлекать финансовые показатели из неструктурированных бухгалтерских документов и банковских выписок |
|---|---|---|---|
| Ценность | Улучшение качества отбора - меньше пропущенного фрода и ложных блокировок | Планирование смен по прогнозу, а не по факту: меньше перерасхода ФОТ в простое и недобора в пике, стабильнее SLA ответа | Снижение частоты рутинных однотипных операций извлечения показателей, снижение риска ошибки при переносе, снижение нагрузки на сотрудников обработки документов |
| Выполнимость | Средняя: табличный скоринг - зрелые методы, но отсутствует эталонноа разметка, нужна программа ее сбора | Высокая: прогноз временного ряда понятный и зрелый класс методов, внедрение не затрагивает клиентский путь | Средняя: разнородные форматы (сканы, фото, Excel) |
| Данные | История операций за годы есть; меток "фрод/не фрод" нет - накапливаются через приоритетную очередь и контрольную выборку | История звонков с почасовой детализацией пишется системой кол-центра; эталон это фактическая нагрузка, разметка не нужна | Исходное извлечение сегодня делает сотрудник вручную - эталон накапливается из его решений |
| Риск | Средний: банковская тайна/ПДн; решение встраивается в правила внутреннего контроля, вердикт остается за человеком | Минимальный: ошибка прогноза это лишняя или недостающая смена, заметна заранее и может быть исправлена вручную | Средний: банковская тайна/ПДн в документах; ошибка поля проверяется сотрудником |
